# Next to do

Next to do 是一个 Android 待办与课表管理应用。可以按日期查看待办、导入课程安排，也可以用番茄钟安排专注和休息。应用使用 Kotlin、Jetpack Compose 和 Material 3，事件与附件保存在本机。

## 当前功能

| 页面 | 可以做什么 |
| --- | --- |
| **Today · 每日提醒** | 左右滑动日期栏切换日期，点「今天」回到当天。曲线随每日事件数量起伏。每日视图中，长期事件、待完成和已完成事件均可在各自分区内拖动右侧手柄或长按调整顺序，顺序会保留；置顶事件在置顶组内排序。全屏页面需选择「自定义顺序」才能拖动。点事件标题查看详情，勾选框用于完成和撤销完成。右下角的 `+` 会在选中的日期新建事件。 |
| **Timetable · 课表速看** | 左右滑动查看上一周或下一周。右上角「···」可拖动滑条选周、修改当前周，以及新建和切换课表。支持导入 Excel 和 HTML，也可以手动添加或编辑课程。 |
| **Add · 添加事件** | 手动创建普通、上课、考试和快递事件，也可以通过 DeepSeek 从图片提取事件草稿。支持日期和时间、到点提醒、原图及自定义的文本、时间、图片或文件属性。已保存的事件可以从详情页编辑。 |
| **My · 我的** | 管理 DeepSeek API 密钥、系统权限和外观。「我的」标题直接叠在每日风景上，下面衔接设置内容；下拉页面可部分或全部展开风景和每日一句，上滑回到设置。番茄气泡可自由拖动，平时仅显示图片，拖动时显示剩余时间；点击就地展开计时控制。 |

## 子事件与 Today 视图

事件编辑页提供「子事件」区域，可将一个主事件拆成多个子事件；也可从 Today 的「＋ 添加子事件」、事件操作菜单或详情页添加。支持两层结构。子事件可以单独编辑名称、描述、时间、提醒和附件，默认跟随主事件日期；单独设置时间后独立安排。

Today 普通页和全屏页均提供「全部」「已完成」「待完成」筛选，启动时默认显示全部。可切换「条状」「树状」视图，视图选择在重启后保留。树状视图支持展开、折叠和圆弧连线；筛选时保留父事件作为上下文，末条连线随可见子事件收尾。条状视图将子事件独立列出，并标注所属主事件。日期曲线和待办数量不会重复计入作为分组的主事件。

全部子事件完成后，主事件自动完成；撤销任一子事件的完成状态，主事件恢复待完成。直接完成主事件时，如仍有未完成的子事件，会先询问是否一起完成。拖动和无障碍排序只调整同级事件，保持置顶分组；删除主事件可选择整组删除，或保留子事件作为独立事件。相关保存和删除使用数据库事务，兼容已有事件数据。

事件编辑页在子事件与时间设置之间提供「添加标签」，普通事件、子事件和持续事件均可使用。预设紧急（红色）、重要（橙色）、一般（蓝色）和可选（灰色），支持多选，再次点击取消；自定义标签可填写名称，在「标签底色」「文字颜色」之间切换，分别选择颜色或输入六位颜色值，并实时预览。文字颜色默认自动适配底色，也可手动指定。点击已有自定义标签可修改名称与颜色，点「×」移除。标签随事件保存，显示在 Today 条状／树状卡片右侧及事件详情中，主事件和子事件分别管理标签。

## 图片识别与事件提醒

1. 在 **My → DeepSeek** 保存自己的 API 密钥。密钥通过 Android Keystore 管理的密钥加密后保存在本机。
2. 在 **Add** 点击「AI 识别图片」并选择原图。应用会将所选图片发送给 DeepSeek，把识别结果填入草稿。核对并编辑后，点击「保存事件」。支持 12 MB 以内的 JPEG、PNG、GIF 和 WebP。
3. 新建事件时始终显示「到点提醒」；未设置时间时会提示先选择事件时间。设置将来的具体时间后，直接开启提醒并保存，无需切换持续事件。持续事件显示「开始时提醒」。清除事件时间后，提醒自动关闭，但选项仍然保留。勾选完成会取消尚未触发的提醒。

## 版本更新

启动应用时会检查 GitHub 最新正式版，也可在 **My → 版本更新 → 检查更新** 手动检查。发现新版后询问是否更新，确认后打开对应版本的 GitHub 发布页下载 APK。

发布新版时，请同步提高 `versionCode` 和 `versionName`，并创建版本标签与之对应的 GitHub 正式 Release（例如 `v1.0.6`）。草稿和预发布版本不参与更新提示。

## 事件与实时提醒（1.0.4）

开启「持续事件」后设置完整的开始、结束日期与时间，默认结束时间为开始后一小时，可跨天；创建页不再提供重复方式。当前正在持续的事件在 Today 时间线下的「长期事件」分区显示，并避免在普通列表重复显示。已有重复事件保留原有安排与完成记录。

时间选择采用小时、分钟双滚轮，可循环滑动；支持浅色、深色主题和无障碍调节，点击确定后才应用，取消保留原值。

Today 日期可直接点击，左上角图标可切换每日、每周和每月待办；时间轴同步改为每天、每周或每月一个点，曲线统计相应范围的事件。没有待办时居中显示插图和提示。左滑事件可置顶或删除；删除重复事件会先确认是否删除整组及后续安排。

课表左上角周数和日期可打开与右上角三个点相同的面板。在 **My → 外观** 可开启「隐藏非本周课程」，仅显示所查看周的课程；默认关闭。

有时间的事件可在编辑页或详情页点击「添加到系统闹钟」，确认后打开手机时钟并填写名称、时刻及支持的每周重复规则。系统接口不支持指定日期、每月、调休或轮班规则，需要在时钟中核对。系统闹钟独立保存，修改或删除事件后需单独处理对应闹钟。

在 **My → 实时提醒** 开启后，可分别选择课程倒计时、今日待办统计和番茄钟状态。课程通知突出课程名称、上课时段、节次和地点，提供「详情」入口；应用内胶囊显示距上课／下课的时间，超过一小时使用「1小时20分钟」格式。番茄钟只显示阶段、剩余时间和本轮进度，短计时保留分秒；待办显示数量与事件名称，三类信息分别展示。运行中的番茄钟优先，暂停后不再遮挡课程。系统通知使用原生倒计时并支持暂停／继续番茄钟；后台通过状态变更和时间节点更新。OPPO 专属流体云接入待取得厂商资格后另行适配。

## AI 编辑课表

在 **My** 保存 DeepSeek API 密钥后，点击课表右上角“＋”左侧的 AI 图标。外观编辑支持背景、文字和课程配色、字号、透明度、圆角、间距与节次高度；课程编辑支持添加、修改和删除课程。

生成后先预览真实课表，可查看课程变更明细；只有点击「确认应用」或「确认删除并应用」才会保存。缺少星期或节次的新增课程列入「未指定节次」。外观编辑不发送课程内容，选择课程编辑后才会发送当前课表的课程资料。

课表右上角的导入菜单在 HTML 下方提供「AI解析导入」。可选择 20 MB 以内的 Excel、HTML、PDF、Word 或文本文件，也可从相册选课表截图、粘贴课表文本。开始解析时发送所选资料给 DeepSeek，需使用 My 中保存的 API 密钥；无需固定表头。解析后先核对课程清单或课表预览，确认后追加到当前课表，并过滤已有安排。未识别到星期、节次或周数时会提示核对。

## 外观设置

Today 的事件区域上滑或双击可进入全屏页面；「⋮」可设置排序及背景。「My → 外观」可以切换课表与 Today 背景同步，默认开启，关闭后可分别使用模板或相册图片。课表外观里长按背景打开「文字」，可以预览调整头部、左侧时间与课程字号，确定后返回编辑页，点击保存生效。

Today 全屏页双击空白处可返回日期页面。课表底栏采用上滑淡入、下滑淡出，背景固定，滚动及底栏显隐时保持静止。

## 本地运行

### Android Studio

1. 在 Android Studio 打开包含 `settings.gradle.kts` 的项目根目录。
2. 在 SDK Manager 安装 **Android SDK 36.1**。项目的最低运行版本是 **Android 8.0（API 26）**，目标版本是 **API 36**。
3. 在 Gradle 设置中选择 **JDK 25**。如果 Android Studio 的 Embedded JDK 是 25，可以直接选择它。项目通过 Gradle Wrapper 使用 **Gradle 9.6.0**，Android Gradle Plugin 版本为 **9.4.0**。
4. 等待 Gradle 同步完成。在 Device Manager 启动模拟器，或连接已开启 USB 调试的安卓手机。
5. 选择 `app` 运行配置和目标设备，点击 **Run** 启动。需要下断点时点击 **Debug**。

### 命令行构建

在项目根目录运行与系统对应的命令。

**Windows PowerShell**

```powershell
.\gradlew.bat :app:assembleDebug
```

**macOS 或 Linux**

```sh
./gradlew :app:assembleDebug
```

命令行构建需要可用的 JDK 25 和 Android SDK。首次构建会下载 Gradle 和项目依赖。构建后的调试包位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 导入课表

在 **Timetable** 点右上角的导入图标，选择 **Excel 导入**（`.xlsx`）或 **HTML 导入**（`.html` / `.htm`）。核对预览后点击「确认导入」，课程会保存到当前课表。HTML 可以使用与 Excel 相同表头的课程明细表，也可以使用带星期列、数字节次行的周课表。

| 表头 | 填写方式 |
| --- | --- |
| 课程名称 | 每条课程安排填写一个课程名。 |
| 星期 | 可用 `1` 到 `7`（周一到周日），也可填写 `周一`、`星期一` 等。 |
| 开始节数、结束节数 | 填写正整数，结束节数大于或等于开始节数。星期和两列节次都留空时，课程归到「未指定节次」。 |
| 老师、地点、周数 | 可选。周数按表格原文展示，支持 `1-8` 等表示方式。 |

请保留「课程名称」「星期」「开始节数」「结束节数」四个必需表头。

点击右上角「+」可直接录入。可填写星期和节次，也可选择「未指定节次」。点击已有课程卡片即可编辑。

## 番茄钟与系统权限

### 每日风景与每日一句

My 的设置入口分为「功能」「自定义选项」「隐私与权限」「关于」，使用浅灰背景和白色分组卡片；分组名位于卡片外，条目的说明以小号灰字放在主标题下方。「自定义选项」提供课程显示、背景同步以及「自定义 Tab 栏」。Add 和 Tomato 底栏入口可分别显示或隐藏，选择会保存；关闭 Add 底栏入口后，仍可从 Today 添加或编辑事件。Tomato 直接切换到专注／统计页面，沉浸专注时隐藏底栏。点击其他设置入口后展开详细设置。

My 页以每日风景作为通栏页头和页面底图，「我的」标题直接叠在图片上，设置内容自然衔接在下方。向下拖动页头或在设置列表顶部继续下拉，可逐步露出半屏或整屏风景与每日一句；向上拖动回到设置，系统返回键先返回设置状态。风景使用必应每日图片，并保留图片实际日期、版权说明与来源；每日一句保留作者、作品和来源链接。

默认优先请求 `https://api.rkgua.cn/api/daily`；当服务、HTTPS 证书或部分数据不可用时，图片与句子分别回退到必应首页图片接口及[一言公共接口](https://developer.hitokoto.cn/sentence/)。图片和句子在线获取，没有内置固定句库。当天的句子缓存在本机，北京时间换日后更新；图片元数据每小时检查一次，图片文件缓存在应用私有目录。无法联网时保留可用缓存，首次没有图片时显示标明的本地备用背景，没有句子时显示占位提示。

展开后点击「来源」，可以切换是否优先自有 API，并修改聚合接口、必应格式图片接口和一言格式句子接口的 HTTPS 地址。聚合接口沿用轻量级每日内容 API 的 `image`、`quote` 结构；公共来源不会绕过 HTTPS 证书验证。

**My 页的番茄气泡**默认与「我的」标题对齐，只显示番茄图片，可在页面内上下左右自由拖动；拖动期间在旁边显示当前剩余时间，松手后收起时间。单击气泡展开快捷控制和「今日时间」圆环，双击进入包含「专注」「统计」两个 Tab 的番茄空间，也可从快捷控制点击「专注与统计」。页头和设置区域保留柔和的渐变过渡，设置卡片间距缩小。

番茄空间支持专注计时、5 分钟小憩、沉浸专注和重复专注计划。默认专注 25 分钟、短休息 5 分钟，每完成四轮专注安排 15 分钟长休息。当前阶段结束后会切换到下一阶段，点「开始专注」或「开始休息」继续。收起控制卡片、切换标签或退出应用不会重置计时；通知中的番茄钟入口在启用 Tomato 时打开该标签，否则打开 My 的快捷控制。专注计划到点启动计时并提醒，已有计时继续运行；重启及时间、时区或权限变化后会重新安排。

今日圆环分别记录番茄专注、休息及实际系统屏幕固定的时间，三类互不重复，暂停不计时。统计支持累计时长与次数、日／周／月分布、月历、记录列表和文字分享；历史记录从接入此功能后开始保存。沉浸页的「固定当前屏幕」由 Android 系统确认，可通过系统手势或页面入口退出；普通沉浸不计为屏幕固定时间。

在 **My → 系统权限** 可分别查看通知总开关、事件／专注／计划的响铃通道、精确闹钟和锁屏全屏提醒状态，并调整闹钟音量。可点击「5秒后测试事件提醒」或「5秒后测试专注提醒」检查实际效果；测试不会修改事件或计时。悬浮窗权限独立管理，到点提醒不依赖悬浮窗授权。

事件到点和专注结束使用系统闹钟用途的声音与振动，最长一分钟；可从提醒页、通知操作或滑掉通知停止。应用在前台时打开提醒页，锁屏时由 Android 根据全屏提醒授权决定是否弹出，未授权时保留系统通知。提醒的声音、振动、重要性仍尊重各类通道设置；通知总开关打开不代表响铃通道已开启，闹钟音量为零也不会响铃。

允许精确闹钟后，用户设置的到点提醒使用系统可见闹钟调度，降低休眠配额造成的延迟；未允许时仍会安排提醒，但可能延迟。重启、校时或重新授权后，恢复最近 15 分钟内尚未投递的事件提醒，较早事件不会集中补响。系统强制停止、部分厂商的自启动／后台限制以及勿扰设置仍可能阻止或静音提醒，请在对应系统设置中检查。

「系统电池优化豁免」提供 Android 通用授权入口，不代表厂商自启动、后台弹出等开关已全部开启。权限页根据品牌提供启动和后台管理指引，涵盖荣耀、华为、小米／Redmi／POCO、OPPO／一加／realme、vivo／iQOO、三星、Google／Pixel、Motorola／联想、魅族、中兴／努比亚／红魔、ASUS／ROG、Sony、TECNO／Infinix／itel、Nokia／HMD、Nothing／CMF；未知品牌保留通用流程。

部分品牌提供启动管理快捷入口，实际使用前检查入口存在、已启用、可公开访问；系统改版或入口不可访问时退回应用详情、系统设置，并显示提示。精简系统没有设置页面时提示手动处理，不会因跳转失败崩溃。厂商专有开关没有统一的状态读取接口，因此只提示手动检查，不宣称已经授权。以上为品牌识别、指引及入口兼容处理，并非每个型号已通过实测；具体菜单和可用性随系统版本变化。

权限页显示设备型号及 Android 版本，提供应用详情、电池与后台管理、锁屏和弹出通知入口。建议保持前台、切换到其他应用、锁屏后分别执行五秒测试。系统强制停止不等于正常切到后台，强制停止后需重新打开应用恢复提醒。

## 项目结构

- `app/src/main/java/com/nexttodo/app/` 存放 Compose 页面、事件存储、课表解析和番茄钟逻辑。
- `app/src/main/res/` 存放底栏图标、主题和文件共享配置。
