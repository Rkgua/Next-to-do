# Next to do

Next to do 是一个 Android 待办与课表管理应用。可以按日期查看待办、导入课程安排，也可以用番茄钟安排专注和休息。应用使用 Kotlin、Jetpack Compose 和 Material 3，事件与附件保存在本机。

## 当前功能

| 页面 | 可以做什么 |
| --- | --- |
| **Today · 每日提醒** | 左右滑动日期栏切换日期，点「今天」回到当天。曲线随每日事件数量起伏。同一天有两条以上待办时，可拖动右侧手柄排序，顺序会保留。点事件标题查看详情，勾选框用于完成和撤销完成。右下角的 `+` 会在选中的日期新建事件。 |
| **Timetable · 课表速看** | 支持从本机选择 `.xlsx`，也可选择其他课表 App 导出的兼容 `.xlsx`。确认导入前可以预览，重复的课程安排会自动去重。 |
| **Add · 添加事件** | 手动创建普通、上课、考试和快递事件。可填写名称、描述、日期和时间、原图，以及自定义的文本、时间、图片或文件属性。已保存的事件可以从详情页编辑。 |
| **My · 我的** | 管理 DeepSeek API 密钥、系统权限和外观。外观支持浅色、深色及跟随系统。番茄钟支持专注、短休息和长休息，可暂停、继续、重置和调整时长。 |

DeepSeek 密钥通过 Android Keystore 管理的密钥加密后保存在本机。图片识别、普通事件到点提醒和手动录入课表属于后续功能。

## 本地运行

### Android Studio

1. 在 Android Studio 打开包含 `settings.gradle.kts` 的项目根目录。
2. 在 SDK Manager 安装 **Android SDK 36.1**。项目的最低运行版本是 **Android 8.0（API 26）**，目标版本是 **API 36**。
3. 在 Gradle 设置中选择 **JDK 25**。如果 Android Studio 的 Embedded JDK 是 25，可以直接选择它。项目通过 Gradle Wrapper 使用 **Gradle 9.6.0**，Android Gradle Plugin 版本为 **9.4.0**。
4. 等待 Gradle 同步完成。在 Device Manager 启动模拟器，或连接已开启 USB 调试的安卓手机。
5. 选择 `app` 运行配置和目标设备，点击 **Run** 启动。需要下断点时点击 **Debug**。

### 命令行构建

在项目根目录运行与系统对应的命令。

**Windows PowerShell**

```powershell
.\gradlew.bat :app:assembleDebug
```

**macOS 或 Linux**

```sh
./gradlew :app:assembleDebug
```

命令行构建需要可用的 JDK 25 和 Android SDK。首次构建会下载 Gradle 和项目依赖。构建后的调试包位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 导入课表

在 **Timetable → 导入 Excel** 选择 `.xlsx`，核对预览后点击「确认导入」。从其他课表 App 迁移时，先在原 App 导出 `.xlsx`，再通过「从课表 App 导入」选择文件。

| 表头 | 填写方式 |
| --- | --- |
| 课程名称 | 每条课程安排填写一个课程名。 |
| 星期 | 可用 `1` 到 `7`（周一到周日），也可填写 `周一`、`星期一` 等。 |
| 开始节数、结束节数 | 填写正整数，结束节数大于或等于开始节数。星期和两列节次都留空时，课程归到「未指定节次」。 |
| 老师、地点、周数 | 可选。周数按表格原文展示，支持 `1-8` 等表示方式。 |

请保留「课程名称」「星期」「开始节数」「结束节数」四个必需表头。

## 番茄钟与系统权限

在 **My → 番茄钟** 开始计时。默认专注 25 分钟、短休息 5 分钟，每完成四轮专注安排 15 分钟长休息。当前阶段结束后会切换到下一阶段，点「开始专注」或「开始休息」继续。

在 **My → 权限** 可查看授权状态并打开系统设置。开启通知权限后，番茄钟结束时可以在后台发出通知。精确闹钟权限用于准点调度，权限关闭时后台提醒可能延迟。悬浮窗权限可在同一页面管理。

## 项目结构

- `app/src/main/java/com/nexttodo/app/` 存放 Compose 页面、事件存储、课表解析和番茄钟逻辑。
- `app/src/main/res/` 存放底栏图标、主题和文件共享配置。
